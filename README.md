# Summer Recipes

This project features 8 recipes: Cheese burger, BBQ ribs, bacond wrapped hot dogs, pepperoni pizza, lemonade, coconut, strawberry milkshake, and apple juice. Each recipe leads to a page with an image of said recipe, the ingredient list, and basic steps to create the meal. The user is able to navigate back to the home page and view how to make other meals or drinks.

Summer Recipes link: [text](https://seansan06.github.io/summer-recipes/)
